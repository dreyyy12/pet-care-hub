# 🐾 PetCareHub - Frontend Module

PetCareHub adalah platform penyedia layanan lengkap untuk hewan peliharaan, mencakup informasi grooming, layanan kesehatan, katalog produk, hingga kontak pengguna. Repositori ini berisi kode sumber untuk tampilan antarmuka (frontend) web PetCareHub.

---

## 🚀 Fitur Utama

- **Home Page**: Tampilan landing page interaktif dengan hero section dan navigasi utama.
- **About Us (`tentang.php`)**: Informasi profil dan visi-misi PetCareHub.
- **Services (`service.php`)**: Layanan perawatan hewan (grooming, pemeriksaan kesehatan, dll.).
- **Product (`produk.php`)**: Katalog produk dan perlengkapan hewan peliharaan.
- **Contact (`kontak.php`)**: Formulir dan informasi kontak / lokasi.
- **Authentication**: Antarmuka alur masuk/daftar (`login.php`).
